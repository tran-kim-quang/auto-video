# Auto Video Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm giao diện web dùng chung qua LAN cho auto-video: upload cây thư mục, quét folder lá, tạo video + `vi.vtt` (sinh từ `report.json`), quản lý/nhân bản giọng qua VoiceStudio, hàng đợi tối đa 3 bài, tải video/zip.

**Architecture:** Package mới `video_workflow/web/` (FastAPI + file tĩnh HTML/JS/CSS) bọc pipeline hiện có. Các khối thuần (quét folder lá, sinh VTT, làm sạch đường dẫn upload, publish `output/`) là module độc lập có test riêng. Một `GpuArbiter` điều phối mọi lời gọi VoiceStudio (job FIFO + yêu cầu tương tác được ưu tiên); `JobScheduler` chạy tối đa 3 job bằng thread; pipeline chỉ được thêm 2 "guard" quanh bước sinh giọng và xuất slide.

**Tech Stack:** Python ≥ 3.12, FastAPI, uvicorn, python-multipart, httpx (test), pytest, HTML/CSS/JS thuần (không Node), PyInstaller (Windows).

**Spec:** `docs/superpowers/specs/2026-10-19-web-ui-design.md` — đọc kèm; mọi mục §N bên dưới trỏ vào spec này.

## Global Constraints

- Python ≥ 3.12; chạy trên Windows (server thật, PowerPoint COM) và Linux (LibreOffice + Poppler).
- Không đổi `VoiceStudioConfig` (engine `omnivoice`, `Vietnamese`, steps 32, seed 42, speed 0.9, `max_chunk_chars` 300, postprocess, crossfade 50 ms).
- Giữ cơ chế 1 WAV/slide; không gộp slide khi sinh giọng.
- Không dùng Whisper/ASR để tạo phụ đề.
- Thư mục làm việc mặc định `Path.home() / "video_and_cc"`, gồm `uploads/`, `work/`, `tts-cache/`, `state/`, `logs/`.
- `output/` của folder lá chứa đúng `<stem pptx>.mp4` và `vi.vtt`.
- Mặc định `MAX_ACTIVE_JOBS = 3`, `GPU_SLOTS = 1`, bind `0.0.0.0:8080`.
- Giới hạn upload 1 GB (`1_073_741_824` byte) mỗi batch; file ghi âm tối đa 20 MB, đuôi `.wav`/`.mp3`/`.m4a`.
- Giọng mặc định ban đầu `599fc048`.
- VTT: tách tiếp câu > 90 ký tự; gộp cue < 600 ms; ETA mặc định 0,032 giây/ký tự + 120 giây/bài.
- Toàn bộ chữ hiển thị cho người dùng bằng tiếng Việt.
- Không sửa hành vi giao diện Tkinter; toàn bộ test hiện có phải pass: `.venv/bin/python -m pytest -q`.

## Review Focus

1. Tên file/folder tiếng Việt dạng NFD (upload từ macOS) → lưu và quét như NFC, không bị coi là file khác. *(test ở Task 3, Task 1)*
2. Kịch bản `.txt` lưu UTF-16 / ANSI từ Notepad → folder lá báo "Kịch bản không đọc được (cần mã hoá UTF-8)", không làm sập quét. *(test ở Task 1)*
3. Hai người cùng bấm Tạo cho cùng một folder lá → lần thứ hai bị từ chối, không có hai job ghi chung `output/`. *(test ở Task 10, Task 13)*
4. Xoá giọng đang được job chờ/chạy sử dụng → bị từ chối kèm số bài đang dùng. *(test ở Task 11)*
5. Upload bị đứt giữa chừng hoặc vượt 1 GB → không để lại batch dở dang trong `uploads/`. *(test ở Task 3)*

| 2 file `.txt` | `"Có 2 file .txt"` |

| không có `.txt` | `"Thiếu file kịch bản .txt"` |

| kịch bản không decode UTF-8 | `"Kịch bản không đọc được (cần mã hoá UTF-8)"` |
| slide cuối kịch bản ≠ số slide | `f"Kịch bản có {last_slide_id} slide, PPTX có {slide_count} slide"` |

### Task 2: Sinh WebVTT từ report (`vtt.py`)

**Files:**
- Create: `video_workflow/vtt.py`
- Test: `tests/test_vtt.py`

**Interfaces:**
- Produces:
  ```python
  def split_cue_texts(text: str, max_chars: int = 90) -> list[str]
  def format_vtt_timestamp(ms: int) -> str            # luôn "HH:MM:SS.mmm"
  def render_vtt_from_report(slides: Sequence[Mapping[str, Any]], *, max_chars: int = 90, min_cue_ms: int = 600) -> str
  ```
  `slides` là `NarratedBuildReport.slides` (mỗi phần tử có `text`, `start_ms`, `end_ms`).

Thuật toán theo spec §9. Chia thời gian nguyên (tránh trôi do làm tròn):

```python
weights = [len("".join(t.split())) or 1 for t in texts]
total, acc, bounds = sum(weights), 0, [start]
for w in weights:
    acc += w
    bounds.append(start + round((end - start) * acc / total))
# cue i = [bounds[i], bounds[i+1]]; bounds[-1] == end
```
Gộp cue < `min_cue_ms` vào cue kế tiếp trong cùng slide (cue cuối thì gộp vào cue trước), nối text bằng một dấu cách; slide chỉ còn 1 cue thì giữ nguyên dù ngắn. Escape `&`→`&amp;`, `<`→`&lt;`, `>`→`&gt;`. Đầu ra: `"WEBVTT\n\n"` + mỗi cue `f"{n}\n{a} --> {b}\n{text}\n\n"`, đánh số liên tục toàn file; bỏ slide có `end_ms <= start_ms`.

  ```python
                     "1\n00:00:00.000 --> 00:00:03.500\nCâu một.\n\n"
  ```

**Files:**

**Interfaces:**
- Produces:
  ```python
  class UploadPathError(ValueError): ...
  class UploadTooLarge(ValueError): ...
  MAX_BATCH_BYTES = 1_073_741_824
  def safe_relative_path(raw: str) -> PurePosixPath
  def is_skipped_upload(path: PurePosixPath) -> bool     # output/ (casefold), phần bắt đầu ".", "~$", thumbs.db, desktop.ini
  ```

`store_batch`: ghi vào `uploads/.incoming-<id>/`, file bị `is_skipped_upload` thì bỏ qua; mọi file phải cùng thành phần đầu tiên (folder gốc) — khác thì `UploadPathError("Chỉ upload một folder gốc mỗi lần")`; vượt `max_bytes` → `UploadTooLarge("Batch vượt quá 1 GB")`; lỗi bất kỳ → xoá `.incoming-<id>` rồi raise; thành công → `os.replace` thành `uploads/<id>/`.

### Task 6: Guard quanh sinh giọng và xuất slide (`pipeline.py`)

**Files:**
- Modify: `video_workflow/pipeline.py` (`build_narrated_video`)
- Test: `tests/test_pipeline.py`

**Interfaces:**
- Produces: hai tham số keyword mới của `build_narrated_video`:
  ```python
  synthesis_guard: Callable[[], AbstractContextManager[None]] | None = None   # bọc đúng lời gọi build_narration(...)
  export_guard: Callable[[], AbstractContextManager[None]] | None = None      # bọc đúng lời gọi export_slides(...)
  ```
