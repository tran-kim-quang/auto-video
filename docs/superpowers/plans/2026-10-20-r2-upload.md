# R2 Upload Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nút "Upload lên R2" / "Kiểm tra upload" trên web auto-video: dựng cây export theo quy ước `pyramid-upload-to-r2`, gọi chính các script upload video + phụ đề của repo đó, hiện tiến độ và đường dẫn manifest.

**Architecture:** Module mới trong `video_workflow/web/`: `upload_identity.py` (kiểm tra danh tính bằng `parseVideoPath` thật qua helper Node), `upload_export.py` (dựng cây `video/` và `cc/`), `r2_upload.py` (chạy 2 script tuần tự, đọc stdout/manifest), `UploadService` (một lượt tại một thời điểm, lưu `state/uploads.json`). Một sửa nhỏ ở `pyramid-upload-to-r2` để `SOURCE_DIR`/`OUTPUT_DIR` nhận từ biến môi trường.

**Tech Stack:** Python ≥ 3.12, FastAPI, pytest; Node v24 (`node --test`) cho repo upload; HTML/JS thuần.

**Spec:** `docs/superpowers/specs/2026-10-20-r2-upload-design.md` (đọc kèm; bổ sung cho `docs/superpowers/specs/2026-10-19-web-ui-design.md`).

```python
@dataclass(frozen=True, slots=True)
class UploadRunRecord:      # state.py; uploads.json {"schema_version": 1, "runs": [...]}
    id: str; batch_id: str; dry_run: bool
    status: str             # "running" | "succeeded" | "partial" | "failed" | "interrupted"
    started_at: str; finished_at: str | None
    phase: str | None; current: int; total: int
    video_total: int; video_ok: int; cc_total: int; cc_ok: int
    video_manifest: str | None; cc_manifest: str | None; log_path: str | None
    errors: list[str]
WebStore.load_uploads() -> list[UploadRunRecord]; WebStore.save_uploads(runs: Sequence[UploadRunRecord]) -> None
class UploadBusyError(RuntimeError): ...        # "Đang có một lượt upload khác chạy"
class UploadNotReadyError(ValueError): ...      # lý do tiếng Việt
class UploadService:
    def __init__(self, store: WebStore, layout: WebLayout, repo: Callable[[], Path | None],
                 jobs: Callable[[], Iterable[WebJob]], check=check_upload_identities, runner=run_r2_upload) -> None
        # khởi tạo: run "running" → "interrupted"
    def candidates(self, batch_id: str) -> tuple[list[ExportItem], dict[str, UploadCheck]]
    def start(self, batch_id: str, *, dry_run: bool) -> UploadRunRecord   # chạy nền bằng thread
    def runs(self, batch_id: str | None = None) -> list[UploadRunRecord]  # mới nhất trước
```
